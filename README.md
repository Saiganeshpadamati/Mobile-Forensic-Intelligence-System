# Mobile Forensic Intelligence System

## About
Mobile Forensic Intelligence System is a Python-based mobile forensic intelligence platform designed to support authorized digital investigations. It helps collect, analyze, manage, and generate reports from mobile forensic evidence.

## Features
- Android device acquisition using ADB.
- Digital evidence collection and management.
- SHA-256 evidence integrity verification.
- Forensic artifact analysis.
- Evidence correlation and timeline generation.
- AI-assisted forensic intelligence.
- PDF investigation report generation.
- Web-based dashboard.

## Technologies Used
- Python
- FastAPI
- SQLite
- HTML, CSS, JavaScript
- Android Debug Bridge (ADB)
- ReportLab


## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ForensicX-Mobile-Forensics.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m uvicorn backend.main:app --reload
```

Open in your browser:

```text
http://127.0.0.1:8000
```
